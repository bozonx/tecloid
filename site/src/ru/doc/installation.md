# Установка

Tecloid полностью поддерживается в **Linux с KDE Plasma 6 или GNOME на Wayland** и в **Windows**. Проверенные дистрибутивы: Fedora, Debian, Ubuntu и Manjaro.

macOS, Sway и Hyprland пока не поддерживаются. Сеанс X11 официально не поддерживается, хотя большая часть функций в нём, скорее всего, работает.

Все файлы для установки есть на [странице релизов](https://github.com/bozonx/tecloid/releases).

## Linux

### Установка

| Дистрибутив                  | Файл      | Как установить                                                         |
| ---------------------------- | --------- | ---------------------------------------------------------------------- |
| Debian, Ubuntu               | `.deb`    | `sudo apt install ./tecloid_*.deb`                                     |
| Fedora                       | `.rpm`    | `sudo dnf install ./tecloid-*.rpm`                                     |
| Manjaro и другие дистрибутивы | `.tar.gz` | Распакуйте архив и выполните команды ниже. Программа ставится в `~/.local` |

Установка из архива:

```sh
./install-linux.sh               # установка в ~/.local, без sudo
./install-linux.sh permissions   # один раз: доступ к устройствам (запросит sudo)
```

### Что нужно для работы

- **Доступ к устройствам.** Tecloid должен читать события клавиатуры и писать в `/dev/uinput`. Пакеты `.deb` и `.rpm` настраивают этот доступ сами. При установке из архива доступ выдаёт команда `install-linux.sh permissions`. Права действуют сразу, перезаходить в систему не нужно.
- **Системный портал для ввода текста.** Чтобы работали действия, которые вводят текст, нужен `xdg-desktop-portal` с модулем вашей среды: `xdg-desktop-portal-kde` для KDE Plasma или `xdg-desktop-portal-gnome` для GNOME. Обычно они уже установлены.

### KDE Plasma 6

Дополнительно ничего ставить не нужно. Работают все возможности Tecloid: переназначения, правила для отдельных окон, определение раскладки, системные действия и сочетания клавиш KDE (`kde:`).

### GNOME

Сведения об активном окне и раскладке, а также системные действия Tecloid получает через собственное расширение для GNOME Shell 50. Его нужно установить один раз:

1. Выполните `install-gnome-extension.sh`. Скрипт лежит в архиве, а после установки пакета находится в `/usr/share/tecloid/`.
2. Выйдите из сеанса и войдите снова.
3. Включите расширение: `gnome-extensions enable tecloid@bozonx.dev`.

Чтобы в трее появился значок Tecloid, нужно расширение AppIndicator. Без него настройки тоже открываются, если запустить Tecloid из меню приложений.

Ограничения:

- всплывающие подсказки работают не полностью;
- нет действий «Показать рабочий стол» и вызова истории буфера обмена;
- сочетания клавиш KDE (`kde:`) в GNOME недоступны.

### Обновление и удаление

Пакеты `.deb` и `.rpm` обновляются и удаляются обычным менеджером пакетов. Если Tecloid установлен из архива, закройте программу и запустите `install-linux.sh` из нового архива. Удаление:

```sh
~/.local/lib/dev.bozonx.tecloid/install-linux.sh remove-permissions   # по желанию
~/.local/lib/dev.bozonx.tecloid/install-linux.sh uninstall
```

Настройки и раскладки сохраняются и при обновлении, и при удалении.

## Windows

### Установка

Скачайте ZIP-архив, распакуйте его в любую папку и запустите `tecloid.exe`. Программа переносимая, установщик ей не нужен.

### Что нужно для работы

- [Microsoft Visual C++ Redistributable v14](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).
- Исполняемый файл не подписан, поэтому при первом запуске Windows SmartScreen может показать предупреждение. Нажмите «Подробнее», затем «Выполнить в любом случае».

### Ограничения

- Переназначения действуют сразу на все клавиатуры. Выбрать отдельную клавиатуру нельзя.
- На экране блокировки и в запросах контроля учётных записей (UAC) переназначения не работают. Окна программ, запущенных от имени администратора, могут не принимать ввод от Tecloid.
- Недоступны действия перехода на виртуальный рабочий стол по номеру и переноса окон между рабочими столами.
- Переназначения проверены в виртуальной машине. Работа на реальном компьютере, в том числе после выхода из сна, пока не подтверждена.

## Другие системы

- **Sway, Hyprland.** Переназначения, скорее всего, работают, но остальные функции не проверялись.
- **X11.** Перехват клавиш не зависит от графического сервера, поэтому переназначения работают. Правила для окон и ввод текста работают с ограничениями.
- **macOS.** Запускается только окно настроек. Перехват и переназначение клавиш не реализованы.
