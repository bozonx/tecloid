# Установка и поддержка операционных систем

Полная поддержка Tecloid доступна в **Linux с KDE Plasma и Gnome**, а так же на **Windows**. MacOS, Linux дистрибутивы на базе Sway и Hyprland на данный момент не поддерживается. X11 официально не поддерживается, хотя скорее всего почти все работает.

## Linux

[Скачать Tecloid для Linux](https://github.com/bozonx/tecloid/releases)

Для Debian и Ubuntu предусмотрен пакет `.deb`, для Fedora — `.rpm`. Для установки в домашний каталог предусмотрен архив `.tar.gz`. Чтобы переназначения работали, Tecloid нужен доступ на чтение к устройству клавиатуры и на запись к `/dev/uinput`. Для ввода текста нужен системный портал `xdg-desktop-portal` с модулем для вашей среды рабочего стола.


| Среда                       | Что работает и какие есть ограничения                                                                                                                                                                                                                                                                                                                                             |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **KDE Plasma 6 на Wayland** | Основная проверенная среда. Работают переназначения, правила для отдельных окон, определение раскладки и сочетания клавиш KDE.                                                                                                                                                                                                                                                    |
| **GNOME на Wayland**        | Поддержка экспериментальная. Для правил по активному окну, определения раскладки и системных действий установите комплектное расширение для GNOME Shell 50 с помощью `install-gnome-extension.sh`, затем войдите в сеанс заново и включите расширение. Для значка в трее нужна поддержка AppIndicator. Действия «Показать рабочий стол» и вызов истории буфера обмена недоступны. |


## Windows

[Скачать Tecloid для Windows](https://github.com/bozonx/tecloid/releases)

Для Windows предусмотрен переносимый ZIP-архив. Для запуска нужен Microsoft Visual C++ Redistributable v14. Исполняемый файл без цифровой подписи. Переназначения прошли проверку в виртуальной машине. Работа на физическом оборудовании, в том числе после выхода из сна, пока не подтверждена.

- Переназначения действуют сразу для всех клавиатур текущего сеанса. Выбрать отдельную клавиатуру нельзя.
- На экране блокировки и в запросах контроля учётных записей (UAC) переназначения не работают. Окна программ, запущенных от имени администратора, могут блокировать ввод от Tecloid.
- Действия для перехода на виртуальный рабочий стол по номеру и переноса окон между рабочими столами недоступны.
