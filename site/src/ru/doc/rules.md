### Назначение для одного приложения

Допустим, вы хотите, чтобы F8 выполняла команду только в Blender. Создайте правило для F8, выберите действие и в условии активного окна укажите идентификатор приложения `org.blender.Blender`. Проверьте F8 сначала в Blender, затем в другом приложении. Во втором окне это правило применяться не должно.

Если важно конкретное окно программы, используйте условие по заголовку. Например, `title:Preferences` совпадает с заголовком, содержащим слово Preferences без учёта регистра. Учитывайте язык интерфейса приложения.
