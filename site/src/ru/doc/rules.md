# Правила и триггеры

Триггер — то, что вы нажимаете на устройстве. Действие — то, что получит приложение. Одной физической клавише можно поручить разные задачи в зависимости от окна, длительности нажатия и соседних клавиш.

## Назначьте F8 для одного приложения

1. Откройте **Правила → Добавить правило**, выберите триггер **F8** и действие при коротком нажатии, например **Home**.
2. В условиях активного окна укажите идентификатор нужного приложения, например `org.blender.Blender` для Blender. Сохраните карту и включите маппер с этой картой.
3. Проверьте действие в Blender, затем в другом окне. Если других назначений нет, во втором окне программа получит обычную F8.

Для одного триггера побеждает первое сверху включённое правило с подходящими условиями. Поэтому ставьте исключение для Blender выше общего правила F8. Для проверки можно временно выключить правило, сохранив его назначения.

## Выберите жест

- **Короткое нажатие.** Выберите [действие](./actions), оставьте исходную клавишу или явно подавите нажатие. Например, Caps Lock можно подавить при коротком нажатии и использовать только для доступа к слою.
- **Удержание.** Выберите [слой](./layers), который будет действовать до отпускания. В расширенных параметрах можно выбрать и клавишу, которая останется зажатой. Например, Caps Lock может отправлять Esc при коротком нажатии и служить Ctrl при удержании. В режиме разработки доступно также однократное действие после длительного удержания.
- **Двойное нажатие.** Для одиночной клавиши задайте второе действие, например открытие меню эмодзи. Клавишу нужно нажать и отпустить дважды в пределах заданного интервала. При выборе интервала учитывайте, что для распознавания одиночного нажатия мапперу приходится ждать второго.
- **Сочетание как триггер.** Например, левый Shift и левый Ctrl можно нажать в любом порядке в пределах интервала распознавания сочетаний. Сочетание заканчивается при отпускании любой из клавиш. Общий модификатор Ctrl подходит для обеих сторон клавиатуры, а назначение конкретно для левого Ctrl имеет приоритет при пересечении.

## Уточните условия

Все заполненные группы условий должны совпасть. Внутри списка разрешённых окон или раскладок достаточно одного совпадения. Исключённое окно блокирует правило. Если активное окно определить не удалось, правило с исключениями тоже не сработает.

Для приложения используйте его системный идентификатор или полное имя процесса. Здесь `*` означает любое число символов, `?` — один символ. Для конкретного окна используйте, например, `title:Preferences`. Это поиск подстроки без учёта регистра, звёздочка и вопросительный знак в заголовке считаются обычными символами. При смене языка интерфейса заголовок может измениться. Для условия по системной раскладке в Linux используйте короткое имя, например `us` или `ru`. Варианты одной раскладки совпадают с тем же именем.

## Настройте удержание под манеру печати

Если слой на буквенной клавише случайно включается при быстрой печати, попробуйте распознавание удержания **после отпускания другой клавиши**. Для выделенной клавиши слоя удобнее срабатывать **при нажатии другой клавиши**. Тогда стрелкой слоя можно воспользоваться сразу. Это отдельная настройка от порога, после которого удержание распознаётся просто по времени.

Позднее короткое нажатие помогает, если вы чуть передержали одиночную клавишу слоя и отпустили её, так и не воспользовавшись слоем. Для такого триггера без дополнительной удерживаемой клавиши стандартное окно составляет два порога удержания. Установите ноль, чтобы отключить это поведение.
